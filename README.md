# Rapido Ride Analytics Dashboard 🚴

## Project Overview

Power BI analytics project analyzing simulated ride-level mobility data to understand ride demand, revenue performance, customer behavior and operational trends.

## Tools Used

- Power BI
- DAX
- Power Query
- Data Visualization

## Dashboard Pages

### 1. Project Overview
- Dataset description
- Business objectives
- Analysis scope

### 2. Executive Overview
- Total rides
- Revenue analysis
- Completion vs cancellation
- Daily trends

### 3. Location Analytics
- Top pickup locations
- Top destinations
- Popular routes
- Distance vs fare analysis

### 4. Operations Analytics
- Payment methods
- Peak hour demand
- Service performance
- Trip duration analysis

## Key Insights

- Identified major revenue contributors by service category.
- Analyzed peak demand hours for operational planning.
- Evaluated location-based ride patterns.
- Studied fare behavior across distances.

## Disclaimer

This project uses a simulated ride dataset inspired by urban mobility operations and does not represent internal company data.
